A compact chess engine in 4 KB of Python: alpha-beta search with iterative deepening to a fixed node budget, a transposition table, MVV-LVA capture ordering with killer moves, quiescence search over captures and check replies, and an evaluation of material, piece-square tables and bishop pair. Pure Python 3.13 standard library, fully deterministic — no clock, no randomness.

## Run it

```sh
python3 main.py
```
